# 本地视频与音频转写整理

完整理解媒体讲解，分开保存原始证据与书面编辑。流程由执行者结合本地脚本完成，可用于支持读取技能说明、处理文件并运行命令的环境。支持 FFmpeg 可读取的视频和音频，包括 MP4、MOV、MKV、MP3、M4A、WAV、FLAC、OGG、OPUS；按媒体轨道识别类型，音频封面不视为视频。

## 输出路径与交付结构

默认输出根为当前项目的 `output/`。以源文件去扩展名作为单篇目录名；用户明确指定简化名称时沿用。

- **源文件在课程或素材目录内：** `output/<原父目录名>学习/<媒体名称>/`。例如 `原视频/示例课程/01.基础概念.mp4` → `output/示例课程学习/01.基础概念/`。音频遵循同一规则；不同源目录中的同名媒体分开保存。
- **散落在项目根的单个文件：** `output/<媒体名称>/`，不把项目根名称当课程名。`media.py prepare` 以 `--root` 的父目录作为项目根；其他位置的散文件可用 `--ungrouped` 明确指定。
- **分组名已以“学习”结尾：** 不重复追加。嵌套素材需要使用上层课程名时，用 `--group '课程名'` 明确分组；默认采用源文件直接父目录名。
- **用户明确指定输出布局或既有目录：** 尊重指定路径，用 `--group`、`--ungrouped` 和 `--lesson` 对应。更新技能本身不自动迁移已交付资料。用户要求迁移时保全原始文件并重算源文件相对路径，不能只移动文件夹后留下失效索引。

视频交付：

```text
output/<原目录名>学习/<视频名称>/
  音频书面稿.md                   完整讲解的书面化正文，无时间戳
  images/                         仅在正文实际引用图片时创建
  原始层/
    原始音频逐字稿.md             完整原始 ASR 文字与段级起止时间
    原视频字幕.srt                有原字幕文件/字幕轨才保留，保持来源格式
    原视频字幕_OCR.srt            仅烧录/位图字幕的 OCR 结果
    关键帧截图/                   仅有精选信息画面时创建，保留原尺寸
  temp/
    chapters.json                 章节定位、正文关联、校订与证据索引
    audio/                        可独立收听的原编码音轨
    transcripts/                  原始 ASR JSON、校订依据及必要 OCR 数据
    process/                      必要媒体数据或有复用价值的方法
```

纯音频交付保持相同文本与证据层级：

```text
output/<原目录名>学习/<音频名称>/
  音频书面稿.md
  原始层/
    原始音频逐字稿.md
    原音频字幕.srt                可选：用户提供的原字幕，保持来源格式
  temp/
    chapters.json
    audio/
    transcripts/
    process/
```

音频不创建 `images/`、`原始层/关键帧截图/`、OCR 画面或其他图片目录，也不生成视频字幕。没有原字幕就省略字幕文件；原有 VTT、ASS、SSA 不强制转为 SRT。只创建实际存在且有用途的文件与目录。主交付为书面稿 Markdown，不默认重复生成 TXT、带轴校订稿、学习笔记、Word 或 ASR 字幕。

`temp` 只保留支持收听、回查、修订或复用的数据。完成后删除无用预览、试跑、日志、重复输出、可再生成且不再使用的 ASR WAV 与空目录。模型、虚拟环境和大量 OCR 裁剪帧留系统缓存或临时目录。源视频、源音频与用户字幕不改写。技能可放在工作目录或执行环境的技能目录中，脚本和参考资料相对技能文件夹定位，不在各媒体交付中复制。

## 执行流程

1. **确认媒体与已有资料。** 检查用户要求、目录内任务说明、源文件、已有输出和引用。FFprobe 检查时长、音轨、字幕轨及非封面视频轨，记录源 SHA-256、`media_type` 和输出分组。多音轨选讲解轨。只有视频需要继续检查烧录字幕。
2. **保全音轨并完整转写。** `scripts/media.py prepare` 支持视频和音频，默认自动分组，复制原编码音轨并生成临时 16 kHz 单声道 WAV。使用可用的本地 ASR，记录模型、参数和识别状态，不覆盖已有原始结果。分块保留重叠，加回源媒体时间偏移，区分误重复与讲师有意重复，保留完整 `raw_asr.json`。
3. **导出原始层。** `scripts/export_transcript.py` 仅从完整原始 ASR 导出 `原始层/原始音频逐字稿.md`。不繁简转换、不去语气词、不纠错、不改自我纠正过程，仅排版和转义显示语法。已有文件不同则停止检查。ASR 不等于人工认证原话，状态写 JSON。
4. **按实际来源保存字幕。** `scripts/export_subtitles.py --subtitle-file` 按字节复制已有字幕；内嵌文本轨尽可能保持格式，必要转换如实记录。视频烧录或位图字幕先 OCR，再用 `--ocr` 导出 `原视频字幕_OCR.srt`，记录来源、抽样与误差。纯音频跳过 OCR；有原字幕可保留为 `原音频字幕.<原扩展名>`。不用 ASR 替代原字幕，不编辑原始字幕与 OCR。详见 [读取与校核方法](references/workflow.md)。
5. **视频精选关键帧；音频跳过。** 发现图示、PPT、代码关键状态、操作结果或承载信息的解释画面时，用 `media.py frames` 保留原尺寸帧，命名 `HH-MM-SS.mmm_核心内容.png`，写入 `原始层/关键帧截图/`。场景切换只是候选，不机械截图；实际引用的帧才复制到 `images/`。音频的封面不提取、不配图。
6. **校核并编辑书面稿。** 通读完整 ASR；视频结合字幕与截图，音频结合回听及实际存在的原字幕，核对术语、数字、否定词、对象和条件。冲突处回听，无法确认保留 `[听不清]` 或 `[术语待确认]`。重要修订记录原文、修改和证据。按下述规则写 `音频书面稿.md`，JSON 关联各节原始段和章节；图片关联只适用于实际有帧的视频。
7. **验证与清理。** `scripts/validate_lesson.py` 检查原始稿一致、源证据保全、路径、章节及原始段覆盖，并按媒体类型检查目录。语义完整与忠实仍需内容复核，程序通过不能证明这些。确认新交付完整后清理已取代的同源成品与无用临时数据，保留必要证据并更新所有路径。

## 书面编辑规则

- **零新增观点。** 不添加原文未提到的解释、外部知识、公式、推测或结论。术语修正需可核对的音频、字幕或画面，不能仅凭常见术语猜测。
- **保留完整实质信息。** 保留讲解顺序、观点、推理、例子、数字、条件、反例和结论，不能变成摘要。删除问候、无意义助词、停顿与机械重复；有意重复中的新信息不可丢弃。
- **保持判断强度与归属。** 保留“可能”“通常”“我认为”“在这种情况下”等限定语，不把经验判断提升为定论，也不擅自弱化强表述。可保留第一人称；不添加整理者的警告段落。
- **自我纠正仅作用于编辑层。** 书面稿采用讲师自行纠正后的最终表述；原始层保留整个过程。数字或对象不清楚时保留待确认标记，不能静默补全或替讲师纠正逻辑。
- **语法与结构。** 合并卡顿、修复倒装与断句；仅在紧邻上下文足以确定时明确代词。按语义分段，3～5 句仅作参考。明确枚举或独立话题才使用二级标题或列表，保持论证关系。
- **正文无时间轴或处理说明。** 直接输出正文，不加套话、原课位置、导航、校核总结、自测、媒体元数据或编辑者“证据边界”等末尾段落。定位、来源和编辑记录放 `temp/chapters.json`；讲师实际给出的适用条件留在对应讲解中。资源文件名可保留时间戳。
- **真实配图只用于视频。** 将视觉指代改为可核实的画面陈述，在对应解释后独立插入 `![内容核心](./images/实际文件名.png)`。没有对应图时保留文字，不编造文件或画面信息。纯音频若提到未提供的图，仅书面化已讲出的信息，不补画面事实、不生成图片链接。

## 索引与脚本

`temp/chapters.json` 的内部资源路径相对该 JSON 所在 `temp/` 解析。新增课程分组会改变源媒体路径的层级，必须通过实际路径计算，例如 Python `os.path.relpath(source, index.parent)`，不能硬编码 `../../../`。`source.media_type` 为 `video` 或 `audio`，`source.file` 指实际源文件，章节覆盖源媒体完整时长。

书面稿各节按源顺序关联所有原始段 ID，每段恰有一次编辑归属，包含被清洗的口语段；覆盖索引不等于逐字保留证明。音频的 `keyframes` 与各节 `keyframe_ids` 使用空数组，不填视频或图片文件路径。schema、字幕来源与精度见 [读取与校核方法](references/workflow.md)。

从 skill 文件夹运行；从项目根运行时加 `media-transcriber/` 前缀。需要 Python 3、FFmpeg、FFprobe，ASR 依赖见 `scripts/requirements-asr.txt`。`prepare` 的 JSON 返回真实 `lesson_directory`，后续命令沿用此路径，不重新猜测输出名。

```bash
python3 -B scripts/media.py prepare '/项目/原视频/课程/教程.mp4' --root '/项目/output'
# 返回 lesson_directory：/项目/output/课程学习/教程
python3 -B scripts/transcribe.py '/项目/output/课程学习/教程/temp/audio/asr_audio.wav' --output '/项目/output/课程学习/教程/temp/transcripts' --model small --language zh --threads 8
python3 -B scripts/export_transcript.py '/项目/output/课程学习/教程'
python3 -B scripts/export_subtitles.py '/项目/原视频/课程/教程.mp4' --lesson '/项目/output/课程学习/教程'
python3 -B scripts/media.py frames '/项目/原视频/课程/教程.mp4' --manifest '/项目/output/课程学习/教程/temp/process/frame_plan.json' --output '/项目/output/课程学习/教程/原始层/关键帧截图'
python3 -B scripts/validate_lesson.py '/项目/output/课程学习/教程'

python3 -B scripts/media.py prepare '/项目/音频/课程/讲解.mp3' --root '/项目/output'
# 返回 lesson_directory：/项目/output/课程学习/讲解；继续转写、原始稿导出、书面编辑与验证，跳过抓图和 OCR。
python3 -B scripts/media.py prepare '/项目/单篇.wav' --root '/项目/output'
# 返回 lesson_directory：/项目/output/单篇
```

视频抓图清单为数组，必须有实际时间和内容标题：

```json
[{"id":"K01","time_seconds":125.4,"category":"architecture","title":"完成后的数据流图","reason":"模块和箭头已写全"}]
```

无音轨的视频仅做视觉分析并记录实际情况，不伪造原始音频稿或书面稿。未出现有用图示时不创建空图片目录。
